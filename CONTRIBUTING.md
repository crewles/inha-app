# Участие в разработке Inha App

Спасибо за интерес к развитию **Inha App**! Приветствуются баг-репорты, идеи улучшений и Pull Request'ы от студентов и разработчиков.

## Как можно помочь
- **Сообщить об ошибке** — откройте Issue с описанием шагов воспроизведения, версии приложения (см. «Настройки»), модели устройства и, при наличии, анонимизированного лога ошибки.
- **Предложить улучшение** — опишите сценарий использования и ожидаемое поведение экрана, парсера или виджета.
- **Отправить Pull Request** — сделайте форк репозитория, внесите изменения в отдельной ветке и откройте PR в ветку `main`.

## Локальная настройка

Требования:
- **Flutter** (channel `stable`, Dart SDK `^3.5.0`)
- **JDK 17** и **Android SDK** (`compileSdk 36`, `minSdk 24`)

Базовые команды:
```bash
flutter pub get
flutter test
flutter analyze
flutter build apk --debug
```

## Структура проекта
- `lib/models/` — доменные модели (`Course`, `Assignment`, `ScheduleEntry`, `InsData` и др.)
- `lib/services/` — клиенты и парсеры `eClass`, `INS`, `EduPage Timetable`, уведомлений, калькулятора GPA и автообновлений
- `lib/data/` — локальное хранилище SQLite (`AppDatabase`)
- `lib/state/` — управление состоянием приложения (`AppState`)
- `lib/l10n/strings.dart` — русская и английская локализация (`RU` / `EN`)
- `lib/ui/` — экраны, темы Material 3, карточки, bottom sheets и тактильный отклик
- `android/app/src/main/kotlin/uz/inha/inhahub/` — нативный Android-код (виджеты рабочего стола, WorkManager, установка APK)
- `test/` — unit и widget-тесты

## Безопасность и приватность
Ни при каких обстоятельствах **не коммитьте** и не прикладывайте в публичные Issues/PR:
- реальные студенческие ID, пароли, cookie-сессии и токены;
- персональные выгрузки HTML/XML из `eClass` или `INS` с оценками и ФИО студентов;
- локальные базы SQLite (`*.db`, `-wal`, `-shm`);
- ключи подписи и конфиги (`android/key.properties`, `*.jks`, `*.keystore`).

Для парсеров в тестах используйте только обезличенные или синтетические HTML-фикстуры.

## Чек-лист перед отправкой PR
1. `flutter test` и `flutter analyze` проходят без ошибок.
2. Все новые тексты интерфейса добавлены сразу для обоих языков (`RU` и `EN`) в `lib/l10n/strings.dart`.
3. Изменения UI проверены в светлой и тёмной темах (`Material 3`).
4. Сообщения коммитов оформлены в стиле Conventional Commits (например, `feat(ui): ...`, `fix(parser): ...`, `docs: ...`).
5. Для правок только документации без пересборки релиза добавляйте `[skip ci]` в заголовок коммита.
